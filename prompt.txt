You are an award-winning frontend engineer and interaction designer.

Design and build a premium templatee for Affinote called:

# Happy Girlfriend Day.exe

This is NOT a greeting card.

This is NOT a scrolling landing page.

This is a tiny nostalgic pixel love game that lasts 2–3 minutes.

The experience should feel like the recipient is playing a cute retro game that was made just for them.

========================================================
CORE IDEA
========================================================

The website pretends to be an old desktop operating system.

The user launches LOVE.exe.

From there they progress through multiple interactive pixel game scenes.

Every click unlocks a new surprise.

The entire experience should feel playful, emotional and memorable.

The goal is to make someone smile before making them emotional.

Think:

• Tamagotchi
• Pokémon dialogue
• Animal Crossing
• Game Boy Advance
• Windows 95
• Stardew Valley UI
• Retro Nintendo
• Cozy pixel games

NOT cyberpunk.

NOT modern SaaS.

NOT glassmorphism.

========================================================
VISUAL STYLE
========================================================

Everything should be pixel art inspired.

Use only flat colors.

No gradients.

No blurred backgrounds.

No glossy buttons.

Use thick pixel borders.

Use chunky shadows.

Use pixel icons everywhere.

Buttons should feel like Game Boy buttons.
